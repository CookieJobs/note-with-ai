日期：2026-11-08。状态：已完成生产发布与公网验收。依据：[已审核 Spec](../superpowers/specs/2026-11-08-notes-feed-design.md)。

## 实现范围

仅笔记列表替换为自适应瀑布流，添加当前账号全库关键词搜索和北京时间展示型月历。现有新建、阅读、编辑、删除确认、关联笔记、绑定笔记对话、其他页面沿用原实现。按后续确认，笔记 tab 左侧完整月历替换最近笔记，其他 tab 侧栏仍维持原实现。

搜索使用独立的页面内只读缓存及请求版本隔离，不替换 useNotes mutation 或新增持久化。历史正文搜索优先非空 contentText，否则回退 content；历史 Markdown 的标记与地址可命中。列表直接使用可信 contentText，只有缺少该投影时做局部文本提取，不对历史库进行重写或承诺完整 Markdown 去标记。
