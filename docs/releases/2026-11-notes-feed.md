# 笔记信息流本地实现与验收

日期：2026-11-08。状态：本地实现完成，未部署生产。依据：[已审核 Spec](../superpowers/specs/2026-11-08-notes-feed-design.md)。

## 实现范围

仅笔记列表替换为自适应瀑布流，添加当前账号全库关键词搜索和北京时间展示型月历。现有新建、阅读、编辑、删除确认、关联笔记、绑定笔记对话、其他页面沿用原实现。按后续确认，笔记 tab 左侧完整月历替换最近笔记，其他 tab 侧栏仍维持原实现。

搜索使用独立的页面内只读缓存及请求版本隔离，不替换 useNotes mutation 或新增持久化。历史正文搜索优先非空 contentText，否则回退 content；历史 Markdown 的标记与地址可命中。列表直接使用可信 contentText，只有缺少该投影时做局部文本提取，不对历史库进行重写或承诺完整 Markdown 去标记。

## 验证结果

- TypeScript：前后端 typecheck 通过。
- 前端：完整 Vitest 71 个文件、603 项测试通过，包含现有保存、草稿、revision、来源返回和侧栏最近笔记回归。
- 后端：完整默认测试 323 项通过、29 项条件跳过；条件式 Mongo 测试仍按既有开关执行。
- 新增真实 Mongo 验证：使用独立临时实例 `127.0.0.1:27028` 与受限测试库，3 项通过，覆盖字面量正则转义、账号隔离、缺失 / 空白 contentText 回退、搜索游标分页、北京时间月边界、闰年及日期去重。没有使用生产数据库。
- Lint：0 errors；11 warnings，其中新增列表首图沿用 `<img>` 的 Next 图片优化提示，其余为既有图片 / Hook 提示。本次未增加图片优化服务。
- 生产构建：前后端构建通过；前端在独立临时目录使用当前源码及现有依赖构建，避免与本机已有开发服务共用 `.next`；路由预算检查通过。
- 浏览器：生产构建配受控 API fixture，验证全库搜索到首屏之外的记录、分页追加、阅读返回保持滚动（450px → 450px）、既有完整 Tiptap 新建并保存、深浅主题；1024、1280、1440、1920px 下无卡片重叠或页面横向溢出，未出现页面 JavaScript 异常。此项为页面交互验收，不冒充远端生产联调。
- 独立代码审核：发现原卡片消失后的焦点回退问题，已改为按原序号选择后继 / 前邻居；补充先失败后通过的深列表回归，审核复核通过。

查询性能使用现有 Schema 索引、10,000 条独立测试记录做本机抽查：普通首屏约 15ms，命中查询约 34ms，无结果查询约 35ms，月历约 5ms。只说明该本机 fixture 下的结果，不作为生产性能保证，也未为此增加索引或搜索基础设施。
