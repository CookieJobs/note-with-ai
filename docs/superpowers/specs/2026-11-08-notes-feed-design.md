# 笔记列表信息流改版 Spec

日期：2026-11-08
状态：独立审核修订后已获用户确认；本地实现完成，尚未部署。实现与验证见[本地验收记录](../../releases/2026-11-notes-feed.md)。

## 1. 目标与范围

在现有 NoteWithAI 产品基础上，将笔记首页的时间分组行列表改为高低错落的卡片信息流，让用户直接看到更多笔记正文，方便回看与发现以前的想法。

本次是**笔记列表改版**，不是工作区重做。附带提供列表关键词搜索及月历统计；为两项能力增加必要的只读接口支持。复用现有笔记数据、权限与分页体系，不新增笔记种类、写入链路或 AI 能力。

### 范围表

| 区域 / 能力 | 本次要求 |
| --- | --- |
| `/notes` 列表态 | 更宽的列表画布、自适应瀑布流卡片、摘要与创建时间 |
| 搜索 | 当前账号全库关键词搜索，结果仍以卡片展示 |
| 月历统计 | 展示指定月的笔记创建数量、记录天数及有记录的日期 |
| 新增笔记 | 沿用现有侧栏和快速记录入口，进入 `/notes?compose=1`，沿用现有编辑器、草稿和保存方式 |
| 阅读、编辑、删除 | 保留现有页面、入口及全部业务保护；卡片点击进入现有阅读态 |
| 关联笔记、AI 对话 | 继续使用现有功能，不更改布局或处理流程 |
| 工作区侧栏 | 按用户后续确认，仅笔记 tab 以完整记录月历替换最近笔记；其他 tab 的侧栏、账户、设置和主题保持现状 |

### 明确排除

- 不采用 HTML 中的底部悬浮输入框、回车直接保存、示例阅读弹窗、示例编辑器或模拟对话。
- 不新增“随手记 / 长笔记 / 含链接”等分类，也不恢复标签、话题目录或频道。
- 不新增语音、独立图片笔记、自动周记、置顶、批量操作、排序模式或视图切换。
- 不迁移历史笔记、不改写正文、不自动生成标题，不调整 AI、推荐或后台任务。
- 不将移动端全面改版列入本次交付；继续遵守现有桌面优先约定。

## 2. 依据与方案选择

视觉参考：[信息流 HTML 原型](../../../design-preview/notewithai-feed-prototype.html)。其卡片构图和留白作为参考；功能范围以本文为准，HTML 中的演示不自动成为需求。

当前列表入口是 [page.tsx](../../../frontend/src/app/notes/page.tsx)，通过 `useNotes` 游标分页，按 `createdAt` 倒序获取笔记。阅读、编辑和关联组件已独立，具备保留列表加载范围与返回滚动位置的机制。

方案比较：

| 方案 | 取舍 |
| --- | --- |
| 只改列表视觉 | 改动最小，但没有本次保留的搜索与月历统计 |
| **列表改版 + 搜索 + 月历统计** | 本 Spec 采用；主要改动在列表，后端增加必要只读查询 |
| 按 HTML 重做整个工作区 | 涉及新建、阅读、编辑和侧栏，超出用户要求，不采用 |

## 3. 页面结构

列表态沿用工作区侧栏和滚动容器。内容区从现有窄阅读列扩展为适合多列卡片的画布；只作用于列表态，阅读和编辑仍使用现有列宽。

从上到下为：

1. 现有笔记页标题与快速记录入口，快速记录仍打开现有新建页。
2. 列表工具行：最近记录 / 搜索结果、关键词搜索框及搜索清除按钮。
3. 卡片信息流，使用主内容区全部可用宽度。
4. 现有“加载更早的笔记”及分页状态。

按用户后续确认，完整月历统计区移至笔记 tab 的左侧场景区，替换最近笔记。月历不再放在卡片区右侧或工具行下方；主内容完整留给卡片。笔记阅读 / 编辑期间月历仍保持挂载，保留选择月份。侧栏收起时隐藏，窄窗沿用现有抽屉；其他 tab 的最近笔记或对话历史保持原状。

默认以卡片宽约 280–360px、间距约 20px 为布局目标，根据**主内容可用宽度**分为 1–4 列，不强行在窄桌面排三列。1440×900、1280×800、1024×768 为主要验收尺寸，同时检查现有侧栏折叠边界。深浅主题复用现有 tokens；不增加主题或整体换肤。

## 4. 卡片规则

- 内容顺序：可选标题 → 正文摘要 → 可选首图 → 创建时间。
- 标题有值才显示，最多两行。无标题笔记直接从正文开始，不展示虚构的“无标题”标题，也不写回标题。
- 摘要以实际列表 DTO 的 `contentText` 为主，缺失或为空时回退 `content`。当前列表 DTO 不保证返回 `excerpt`，不能因类型中声明了该字段就依赖它。历史 `content` 可能仍含 Markdown，并不存在可直接复用的完整去标记契约；允许在列表展示层做局部、只读的文本提取，例如去除常见格式标记、过滤独立图片行。不引入列表富文本渲染器，不改数据库或编辑器，不直接渲染原始 HTML。
- 正文最多约 6 行，保留自然换行；短笔记按实际高度展示。长文截断，点击后阅读完整内容。
- 首图复用现有 `noteReferenceDisplay` 从 `contentJson` 或历史正文中提取的资源，最多一张，固定预留比例以减少跳动。当前列表 DTO 不保证返回 `firstImageSrc`，本次不为首图新增 DTO 字段、图片服务或历史回填。图片地址沿用现有阅读内容的处理边界，不因信息流扩大可加载协议或引入代理服务；不可用或加载失败时降级为文字卡片。纯图片且无可读正文时，使用“图片笔记”作为内容类型提示，不写回笔记标题。
- 不增加 AI 摘要、装饰插画、随机渐变或新的卡片操作菜单。创建时间沿用现有格式，不显示虚构来源或关联数量。
- 整张卡片为一个可聚焦的阅读入口，Enter 可打开，焦点可见。避免卡片内部嵌套冲突的点击控件。

### 顺序与布局

后端继续以 `createdAt DESC, _id DESC` 稳定排序。前端按此顺序，将卡片逐张放入当前高度最短的一列，同高度时从左到右；DOM、键盘访问和屏幕阅读顺序始终与数据顺序一致。不得使用逐列填满、造成最新记录藏在某列底部的排法。

在既有卡片内容及可用宽度未变时，加载下一页只追加布局，不随机重排既有卡片。窗口变化、编辑或删除、摘要更新及图片失败导致高度改变时，允许对受影响布局重新计算，并尽量保留滚动锚点。图片预留占位以减少跳动。布局计算不得引入新的重型瀑布流依赖或改变现有页面滚动职责。

## 5. 搜索

搜索限定于**当前账号全部笔记的标题和存储正文**，为普通关键词包含匹配；不包含 AI 语义检索、推荐、标签检索、搜索历史或内容高亮。正文优先匹配非空 `contentText`，缺失或为空时回退 `content`，不匹配 AI 摘要、概念或其他派生字段。历史 `content` 中可能包含 Markdown 标记及链接 / 图片地址，首版允许这些原存储文字命中，不承诺严格的“渲染后可见纯文本”检索，也不额外搜索 `contentJson` 的图片属性。首版对去除两端空格后的完整输入做字面量匹配，英文不区分大小写；特殊字符按普通文字处理，不作为正则表达式。

- 输入约 300ms 防抖，中文输入法组字期间不发请求；输入上限 100 个字符。
- 关键词为空时回到普通列表；支持一键清除，清除后恢复进入搜索前的已加载列表与滚动位置。
- 切换关键词重新从第一页开始；结果沿用创建时间倒序及游标分页。旧请求的迟到响应不能覆盖新关键词结果。
- 不为了搜索下载全部笔记，也不对当前已加载笔记做筛选后宣称“全库搜索”。
- 标题显示“搜索结果”；仅显示“已加载 N 条”，不增加结果总数查询。月历统计不随关键词变化。
- 零结果显示“没有找到相关笔记”，提供清除搜索入口；请求失败显示错误与重试，不能伪装为空结果。
- 搜索条件、已加载结果和滚动位置在列表 → 阅读 → 返回后保留；从搜索结果直接编辑再返回时，按最新已保存内容刷新受影响的查询结果。
- 搜索结果不得覆盖全局侧栏的“最近笔记”投影；最近笔记仍来自普通列表的可信结果。

## 6. 月历与统计

这是辅助回看的**展示型月历**。首版不做点击日期筛选、日期范围查询、连续打卡或提醒。

- 默认当前月，可查看上一个 / 下一个月，不进入未来月；保留“回到本月”入口。
- 显示年月、按周排列的真实日期；周一为一周起点，月首尾补空位，不使用原型里的无日期圆点矩阵。
- 当天有独立标记；有记录的日期有可辨识标记，并提供“11 月 8 日，3 篇笔记”形式的可访问说明。不以颜色作为唯一信息。
- **本月笔记**：当前账号、当前选中自然月创建且当前仍存在的笔记数量。查看历史月时标签改为“当月笔记”。
- **记录天数**：上述笔记按创建日期去重后的天数。编辑旧笔记不增加本月笔记或记录天数。
- 月边界及日期统计统一使用 `Asia/Shanghai`，由后端按相应 UTC 时间区间查询；首版不增加时区设置。统计区明确说明按北京时间与创建日期统计。
- 统计与搜索无关，不依据已加载页计算。切月只刷新统计区，不改变信息流、搜索条件或滚动位置。
- 创建或删除成功后刷新受影响月份统计；编辑正文不影响统计。失败显示局部重试，不阻塞列表。加载中、失败、真实零值须区分。
- 快速翻月时只展示当前选中月份的数据；旧月份迟到响应不得覆盖当前月份。账号切换后清除旧账号可见统计，旧请求不得回填。

## 7. 新增、阅读与编辑沿用现状

卡片打开 `/notes?highlight=<id>` 的现有阅读态。保留聊天来源 `fromChat`、返回原对话、未保存保护、来源独立读取以及关联笔记跳转。搜索只出现在列表态；月历仅在笔记 tab 侧栏显示，阅读与编辑时继续保留。

现有快速记录入口与侧栏新建入口仍进入 `/notes?compose=1`，继续使用 Tiptap、本机草稿恢复、可选标题、显式保存及现有快捷键。保存成功后的跳转维持现状；返回普通列表时，新笔记按创建时间进入顶部，统计更新。若返回的是保留条件的搜索结果，仅在新笔记匹配关键词时展示；不匹配时保持搜索条件与正确结果，清除搜索后可在普通列表看到新笔记。

编辑沿用现有入口、页面、revision 冲突保护及保存链路。编辑既有笔记不改变创建时间排序；删除仍走现有确认流程。设置、侧栏与工作区导航继续遵守现有草稿保护。

列表返回优先恢复触发卡片与原视口位置；若卡片已删除或因编辑不再匹配搜索，则恢复邻近位置并给出可用焦点。不得因进入阅读而丢失已加载分页或重复叠加分页结果。

## 8. 最小技术边界

以下为待实现契约，不是现有接口已支持的声明。

| 层面 | 最小必要改动 |
| --- | --- |
| 列表页面与样式 | 列表卡片布局、局部搜索；完整月历移到工作区笔记场景侧栏，通过刷新通知衔接成功写入；不改变其他 tab |
| 列表查询 | 扩展现有 `GET /api/notes`，支持可选 `q`；继续返回 `notes` 与 `pageInfo` |
| 月历查询 | 新增只读 `GET /api/notes/calendar?month=YYYY-MM`，返回 `month`、`timezone`、`noteCount`、`recordedDayCount`、`days: [{date, count}]`；`days` 仅含有记录日期 |
| 查询状态 | 优先保留现有 `useNotes` 普通列表及写入缓存链路；搜索以独立只读查询接入，各关键词分页和各月统计独立缓存；账号切换隔离；写入成功后更新或失效受影响查询 |
| 文档 | 实现落地时同步笔记模块说明和 DESIGN 中列表条款，不借此重写其他产品规范 |

后端继续由认证身份决定 `userId`，不接受客户端指定他人身份。搜索先限定账号再匹配；历史缺少或空白 `contentText` 时按第 5 节回退 `content`，查询口径须与 DTO 回退规则一致，不为上线批量重写历史笔记。必须转义查询字符，使用现有分页大小和输入校验限制。

游标仅用于其所属关键词，不能把某关键词的下一页游标用于另一关键词或普通列表。统计路由须注册在 `/:id` 之前；参数错误返回校验错误，不误入单笔记读取。两项查询均不调用模型、向量、推荐或新增 worker。

搜索不得重写现有创建 / 编辑 mutation、revision 防覆盖、临时笔记合并或富化轮询机制；只在成功写入后同步只读结果，且不得将不匹配的新笔记无条件插入搜索缓存。

不新增数据库业务实体。查询性能以代表性历史库验证；若简单的受控查询达不到可接受响应，应单独评估必要索引，不能默认扩展成搜索平台或数据迁移项目。

## 9. 验收标准

| 场景 | 通过标准 |
| --- | --- |
| 空库、短笔记、长文、无标题、图片缺失 | 状态真实，内容可辨认，无占位假标题或破图 |
| 卡片布局 | 指定桌面尺寸及侧栏折叠后无横向溢出、重叠或正文撑破；深浅主题可读 |
| 顺序与分页 | 创建时间稳定倒序；加载更多不重复、不漏项、不打乱已有卡片；失败可重试 |
| 阅读往返 | 打开真实现有阅读页，返回保留搜索、已加载范围、滚动与可用焦点 |
| 搜索全库 | 能搜到不在第一页的笔记；中文、英文及特殊字符结果正确；历史缺失 / 空白 `contentText` 的回退符合第 5 节口径；切换关键词无旧结果串入 |
| 搜索边界 | 空结果与失败分开；清除恢复普通列表；不污染侧栏最近笔记；不能读取他人笔记 |
| 月历准确性 | 月首月末、闰年、北京时间跨日、同日多篇、零笔记均正确；天数按日期去重 |
| 月历独立性 | 翻月、搜索和分页不互相改变结果；快速翻月无旧响应覆盖；账号切换不展示前一账号统计；统计失败不影响正常浏览 |
| 新增与编辑 | 入口、编辑器、草稿恢复、显式保存和保存后导航照旧；失败或冲突不丢稿、不误报成功 |
| 写入后的列表 | 新增、编辑、删除成功后卡片与相关查询更新；编辑不改变创建时间顺序，高度变化允许锚点保护下重排；搜索中创建不匹配笔记不污染结果，清除搜索后可见新笔记；统计只按创建 / 删除变化 |
| 原有流程回归 | 聊天来源往返、关联笔记、AI 讨论及未保存保护沿用现状，其他页面无视觉改动 |
| 性能与可访问性 | 列表首屏不引入 Tiptap；不为搜索全量下载；键盘顺序、焦点和减少动态效果符合现有规范 |

交付证据包含真实接口联调、针对新增查询和分页状态的测试、上述桌面尺寸的深浅主题截图，以及新增 / 编辑 / 来源往返及笔记侧栏切换的现有回归检查。HTML 演示不能代替生产验收。

## 10. 完成边界

当卡片列表、全库关键词搜索、真实月历统计及上述回归验收通过，本次改动即完成。除已确认的笔记 tab 侧栏月历替换外，任何需要修改新建方式、编辑器、阅读布局、共享导航或其他页面的提议，均应另行确认范围，不并入此次列表改版。

## 11. 独立审核修订记录

2026-11-08，独立代理结合列表 DTO、`useNotes`、`noteReferenceDisplay` 及现有写入链路完成只读审核。主代理核实后采纳 3 项勘正与 3 项边界补充：

- 勘正历史正文处理：不再假定已有完整 Markdown 纯文本归一化；明确只读展示提取与历史存储正文搜索口径。
- 勘正新建返回行为：普通列表置顶，搜索结果只展示符合关键词的笔记。
- 勘正卡片字段来源：不把可选类型声明当成列表实际 DTO；首图复用现有提取逻辑。
- 保留普通列表和写入链路，搜索采用独立只读查询，避免扩大编辑流程改造。
- 补充翻月与切换账号时的异步统计隔离及验收。
- 允许内容或宽度变化时的必要布局重算，同时保护阅读返回与滚动锚点。
