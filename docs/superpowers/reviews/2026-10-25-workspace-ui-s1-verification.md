## 本轮修复的验收问题

1. 从认证页进入工作区时，Next 先恢复历史并卸载编辑器，晚注册的保护读取不到草稿。稳定根边界增加早期 popstate 桥，仅活动工作区订阅处理；认证/后台为空订阅且不包装 history。无日志冷生产构建已复验。
2. 新建网络保存成功后，旧 render 的 loading 仍为 true，导致保护误报失败。改用覆盖真实请求的同步 ref；deferred 回归先红后绿，真实网络保存复验通过。
3. 新建立即消费 URL 导致侧栏无法返回列表。视图改由保留的 URL 意图派生，补真实导航与草稿集成回归。
4. 纯图片既有笔记保存按钮误禁用。已有笔记不再以正文纯文字判断保存可用性。
5. 删除菜单卸载后丢失焦点。显式保留稳定的更多按钮引用，关闭弹窗后恢复。
6. Tailwind 生产重置覆盖单类按钮背景。仅提高对应原生按钮选择器优先级；不修改全局重置或排除页面。
