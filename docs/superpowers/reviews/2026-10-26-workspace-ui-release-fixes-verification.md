## 实际浏览器与数据边界

预览：[本机工作区](http://localhost:3010/notes)，独立构建副本，连接既有本机后端；没有停止用户 3000/3001 服务。

- 使用既有 `@notewithai.local` 独立验收账号，没有操作日常/线上用户。改密前真实保存测试临时修改一条夹具标题，随后恢复原题；本机只读核对恢复为真，revision 为 4，旧回答快照仍分别为 1、2，没有被改写。
- 新增一条 2021 年历史 Markdown 夹具，只在核对 loopback MongoDB、独立用户 ID/邮箱均匹配后幂等插入，不覆盖已有记录；目前该验收账号有 9 条笔记。夹具保留用于复验。
- 历史故障在 loopback 3011 的临时代理中只对一次历史 GET 返回 503，其余请求转发同一 3010 实际产品与服务。点击重试后真实历史和来源恢复、草稿不变；未发送该草稿。代理和额外标签页均已关闭，不修改真实后端或生产网络。
- 没有永久删除记录，没有输入或提交新密码。浏览器工具要求凭据变更交由用户本人操作；R2 的生命周期/身份逻辑由受控回归覆盖，真实改密成功仍保留人工验证边界。未绕过此要求改用接口提交密码。
