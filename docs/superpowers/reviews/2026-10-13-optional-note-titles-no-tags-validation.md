# 可选标题与标签退役：实施及验收记录

日期：2026-10-13。对应 [Spec](../specs/2026-10-09-optional-note-titles-no-tags-design.md) 与 [实施计划](../plans/2026-10-11-optional-note-titles-no-tags.md)。代码在本地 `codex/optional-note-titles-no-tags` 分支，保留原有未提交的视觉改动；未提交、推送、部署或清理线上数据。

## 已落地的行为

- 新笔记标题默认为空；手写标题与正文使用同一保存快照。正文首行不写成标题，清空标题后后台不会补回。
- “AI 生成标题”只由用户点击触发，只填入草稿，支持撤销；失败、超时、限流和迟到响应不覆盖新的编辑。标题与正文共享保存基线，保存期间的新输入继续保留。
- 结构化标签、个人话题入口和自动生成链路退役。旧字段保留在数据库中，正常页面、DTO 和模型输入不再使用；旧写标签请求明确拒绝，退役读取入口返回 410。
- 无标题来源使用原文首行、第二行、真实上海时间或图片线索识别；关怀历史中无法证明是原文日期的时间不显示。列表外原文按 ID 单独读取，有明确的不可用和重试提示。
- 灵感只使用各篇可用的真实标题和兼容摘要，部分可用时继续；全部不可用时解释具体原因，定时任务记录同样的原因，保留旧灵感。

## 真实标题生成质量

14 篇隔离副本实际调用 DeepSeek，14/14 返回有效建议，调用不改写笔记。逐篇评审结果是 5 篇通过、9 篇有用途方面的顾虑、0 篇发现编造或反转核心观点。7 篇很短或标记类记录中，6 篇主要复述正文；7 篇较有内容的记录中，3 篇未充分保留最有区分度的细节。

因此保留主动按钮、允许空标题是成立的。该样本不足以证明普遍生成质量或提示注入抵抗能力；不把“接口成功”当成“标题有用”。本期不继续扩展生成实验或建设画像/记忆引擎。原文及逐篇生成结果仅私有保存在临时目录，本文不收录。

## 过程成本复核与本次裁决

能确认的成本来源是：原计划拆成六步并逐步审查，多次用量限制/会话中断导致恢复和补交接，部分实现已落盘但缺少报告，以及前端测试默认并发曾高 CPU 停滞。流程设计偏重；没有完整用量账单，不能给出准确的浪费 token 或金额。

本次复用已验收 Task 1/2，恢复既有前端实现，限定低一级模型代理的文件范围；互不重叠的前端收尾与灵感兼容并行。Task 4 审查与整体衔接合并为一个独立评审，修复仅做定向复审。前端测试使用单 worker；完整回归只跑一次，后续按实际修复范围验证。

实施裁决：使用现有专用分支及修改前快照，避免覆盖用户待提交的视觉改动；不自动提交混合工作；不另做七代理历史复盘或重复已经完成的实验；保留恢复台账，因为当前改动尚未提交；历史字段不迁移、不删除。实现方向错误时可在本地逐项修正，线上数据没有承担这次实验的修改风险。

## 本地使用与发布要求

产品入口是 `http://127.0.0.1:3000/notes`；`4179` 是先前的实验网页。QA 页面及后端分别为 3200/3101，与真实用户写入隔离。最后服务检查确认 4179、3000、3001、3101、3200 均可响应。

线上发布必须停止旧实例及旧话题 worker，然后同步切换前后端，避免混用旧自动写入链路。回滚版本同样必须保留“空标题可用、禁用自动标题/标签写入”的兼容保护。当前交付仅完成本地实现及上述验证，不等于已发布线上，也不等于新的记忆/进化闭环已经建成。
