# 聊天页面

[page.tsx](page.tsx) 组合真实会话、消息、输入和关联笔记，并向[工作区](../../components/workspace/README.md)登记历史与操作。生产页面复用侧栏 embedded `ChatHistoryPanel`，不再绘制第二列历史或旧顶部导航；隔离渲染保留独立导航 fallback。消息与来源展示见[共享组件](../../components/README.md)，服务端信任边界见[后端服务](../../../../backend/services/README.md)。

## 会话与 URL

普通进入 `/chat` 显示新对话，不自动打开首条缓存或历史。`?session=<id>` 等待当前用户的真实服务端历史，缓存只作暂显；读取失败可重试，失效 ID 明确报错并禁止发送，不回退到其他会话。主动选中其他会话、新建或成功删除 URL 所指会话时移除旧参数；删除失败保留参数和当前状态。

首次发送才创建普通本地会话，`committed` 后同步服务端 ID。历史合并保留请求期间新建且已保存的会话，以及服务端确认的正文和快照，过期加载不能覆盖它们。回复期间切换会话保留用户选择；等待和错误只显示在所属会话，单流未结束时不另启请求、不丢弃其他会话草稿。

从消息、关联栏或抽屉打开来源时，记录当前用户在本标签页中的会话、未发送草稿与阅读位置；30 分钟内返回时消费一次，历史未到则等待对应会话，不换成另一条。恢复期间补载历史不自动滚到底部，主动发送、切换或新建后恢复正常滚动。

## 笔记入口与流式状态

[startNoteConversation](../../services/noteConversation.ts) 保存明确选择的 `sourceNoteId` 与空 `messages`，得到有效服务端 ID 后才进入对话，不请求随机笔记或伪造 AI 开场。新绑定会话提供来源入口和提问提示；旧历史中的真实 AI 开场首问后收起，原消息和回答快照仍保留。每轮读取最新已保存文字，旧回答继续展示当轮 `sourceSnapshot`；发现线索的关联栏排除绑定笔记，无其他记录时不占右侧空间。

有效发送被接受时立即清空输入，失败仅在仍处于原会话且没有后来草稿时恢复问题；相同问题重试不重复追加用户消息。[useChatStream](../../hooks/useChatStream.ts) 只认服务端 `committed` 为保存成功；提前结束或无提交确认的部分回答不能冒充已保存。连续 60 秒无数据或总计 180 秒后解除加载，迟到响应不能覆盖后续请求，reader 清理不能阻塞界面恢复。

删除确认等待真实 Promise，期间禁止重复确认；失败保留历史、弹窗和重试入口。历史搜索仅覆盖已加载会话。布局与主题以 [DESIGN.md](../../../../DESIGN.md) 为准。
