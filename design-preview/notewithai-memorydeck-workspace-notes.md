## 1. 方向与依据

用户已完成一轮工作区迁移，但认为现行界面过于素净。本轮以 2026-10-25 的 Memory Deck 设计稿作为**视觉风格来源**，以 2026-10-26 发布的产品代码（`72dc316`）作为**功能与结构来源**：

- 保留现行左侧栏工作区：笔记 / AI 对话 / 灵感 + 场景最近区 + 账户菜单。
- 保留现行真实功能：可选标题、阅读/编辑分离、未保存保护、每轮 `sourceSnapshot`、相关笔记、灵感三视图、真实画像、设置三分类、深浅主题。
- 不迁移 Memory Deck 的演示能力：抽一张、撞卡、卡片编号、字数统计、聊天次数、小光人格、演示数据重置。
- 不写入无法由现有服务支持的动作：多种聊天模式、保存 AI 回复为笔记、删除撤销、全局搜索、订阅、修改邮箱等。

功能口径按 2026-10-26 发布的 `72dc316` 代码审计整理；风格口径按归档的 Memory Deck 设计稿（2026-10-25）整理。两者都是过程材料，不随本预览入库。

## 2. 保留的视觉 DNA

1. **浅蓝紫画布**：`#eef1ff` 底色与三处 radial 彩光；深色主题换为低亮度版。
2. **纸片卡**：6 套 pastel 卡色（butter / coral / mint / periwinkle / lilac / paper），`0 3px 0` 硬边 + 大柔和投影 + 轻旋转；角部印刷圆环、圆点。
3. **单强调色**：`#266FE1` 只用于主操作、选中、焦点与强调词；深色使用通过 4.5:1 的蓝色变体。
4. **大标题与 mono 元信息**：页标题 38px/800；日期、版本、时间使用等宽字与 8–10px 的小字，形成档案卡气质。
5. **星形助手形象**：保留 Memory Deck 的黄色星形贴纸，作为「AI 回答 / 建议」的视觉符号；产品身份仍写 NoteWithAI，不使用「小光」人格。
6. **实体按钮与胶囊**：主按钮蓝色 + 底部硬影；输入框 10–16px 圆角；弹窗 20px 圆角 + 蓝相遮罩；Toast 深墨药丸。
7. **动效语言**：`cubic-bezier(.22,1,.36,1)`、170ms 悬停、卡片抬升微旋、页面 200ms 进入；支持系统与设置内的减少动效。

## 5. 关键交互

- **快速记录**：Cmd/Ctrl+Enter 或按钮保存；也可「展开编辑」带着草稿进入完整编辑页。
- **阅读动作**：和 AI 讨论、编辑笔记、相关笔记、更多（删除）放在标题行右侧，1440 高度下无需滚动即可到达。
- **未保存保护**：主导航、最近笔记、返回、浏览器后退都会经过「保存未完成的修改？」；提供「继续编辑 / 放弃修改 / 保存并继续」，保存失败不跳转（本预览的保存为本地模拟）。
- **和 AI 讨论**：创建一条绑定笔记的空会话，先到「围绕这篇笔记提问」，不写死开场消息。
- **流式回答**：先显示用户消息，再逐字输出；完成后追加「本次回答依据」，含版本、更新时间和原文折叠。发送文本包含「失败」会进入超时/失败与重试演示。
- **相关笔记**：阅读与对话都排除当前/绑定笔记；对话相关栏说明「回答实际采用的内容见本次回答依据」。
- **灵感**：收藏/取消收藏、忽略/恢复、最近/已保存/已忽略切换、生成中骨架屏；定期发现提供真实字段口径的摘要与设置入口。
- **个人页**：头像预设与姓名首字母、用户名必填 ≤20、改密校验、画像重新分析中的状态、历史画像只读快照。
- **设置**：主题（浅色/深色/跟随系统）、正文字号（15/16.5/18）、减少动效、折叠侧栏、定期发现披露与开关、账户入口。偏好保存在 `localStorage`。
- **响应式**：≥1241px 相关栏并排；≤1240px 改为右侧抽屉；≤980px 侧栏变抽屉；1024 / 980 均保留桌面操作。

## 6. 演示边界

这是可交互的视觉预览，所有数据与请求都在本地模拟：

- 笔记、对话、灵感、画像、来源均为内嵌示例数据，刷新后回到初始状态；只有外观偏好会保留在当前浏览器。
- AI 回答、聊天流、生成灵感、重新分析均为前端定时模拟；没有真实网络请求。
- 修改密码成功只显示成功提示，不执行真实退出登录（认证页不在本次范围）。
- 定期发现开关只改变本地状态，不启动真实调度 worker。
- 失败/分析中/空态等部分状态可通过操作触发；保存冲突、画像数据不足、灵感服务错误等状态本预览没有独立入口。
- 灵感中的示例来源不打开外部站点：点击标题会弹出本地来源预览并标明是示例来源，避免死链；首条 CACLER 来源保留真实外链。
- 为方便评审，顶栏提供设置与主题快捷入口；产品正式入口仍是账户菜单与设置弹窗。笔记列表行的悬停操作簇与首页「最近的一张卡」属于视觉增强，可按产品意见收敛。
- 登录、注册、重置密码、`/admin/**` 不包含在预览内。

## 7. 与生产代码的对应关系

若后续要落到产品代码，建议按以下顺序映射，而不是复制整段 HTML：

1. 把画布、纸片卡、胶囊按钮、颜色/阴影/圆角/动效提取为工作区作用域的 tokens（沿用 `Workspace.module.scss` 的作用域，不写全局 `html.dark`）。
2. 侧栏选中态、品牌区、新建入口、场景最近区按预览样式逐项替换；保留现有导航与偏好持久化逻辑。
3. 笔记列表行、阅读纸卡、相关栏用现有组件结构套新样式；快速记录仍走 `compose=1` 的真实流程。
4. 聊天与来源快照优先替换展示层，保留流式、committed、sourceSnapshot 与相关笔记状态机。
5. 灵感、个人页、设置替换视觉容器，保留服务调用、三视图、画像轮询与设置 controller。
6. 深浅主题、字号、减少动效需要在同一套 tokens 中映射，再用 1440 / 1280 / 1024 / 980 与真实长文回归。
