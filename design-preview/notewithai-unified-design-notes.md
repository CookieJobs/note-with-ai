# NoteWithAI 整合版设计说明

2026-10-23。单文件成品：`2026-10-23-整体UI-DeepSeek与Codex整合版.html`。

以用户提供的 DeepSeek harness + DeepSeek v4.1 Flash 作品为基础，保留笔记优先的产品结构，再由 Codex 补入交互优势。2026-10-24 按用户决定清理其他预览作品，本文件对应唯一保留的整体 UI 主稿；生产前后端代码未修改。

## 用这份预览指导什么

- 视觉：灰白工作台、窄阅读列、统一系统字体与图标，强调色 `#266FE1`。强调色用于主动操作、选中和焦点，其余信息保持中性。
- 页面：笔记列表、独立阅读、编辑、AI 对话、灵感、个人页和设置。
- 改版范围不含登录、注册、重置密码页面，沿用当前产品已实现的样式，不列为待补设计。
- 核心流程：写下记录 → 阅读/编辑 → 围绕记录对话 → 回到引用来源 → 保存新的想法。
- 此文件是可交互的设计参考。正式落地仍应沿用项目现有数据契约、可靠性和安全要求，不能用演示函数替换实际业务服务。

## 保留的基底优势

1. 默认打开笔记；标题可选，无标题记录直接展示正文，不恢复结构化标签或个人话题目录。
2. 阅读和编辑分离，阅读页优先呈现内容。
3. 侧栏随笔记/对话场景显示最近笔记或最近对话。
4. 时间分组列表、具体的示例记录、统一的颜色/字号/间距/圆角 tokens。

## 整合后的交互决策

| 场景 | 预览中的行为 | 目的 |
|---|---|---|
| 普通新对话 | 标题、输入框、建议集中在一组；进入会话后输入框置底 | 让开始输入的动作更明确 |
| 从笔记发起对话 | 笔记原文摘录 → 标识清楚的示例开场提问 → 输入框 | 首问前保留明确上下文 |
| 会话开始后 | 顶部可展开的紧凑原文快照；右侧关联计数排除绑定笔记 | 避免同一篇笔记重复出现 |
| 后续提问/重新生成 | 绑定笔记会话复用开始时的原文快照；新来源保留回复时的快照 | 阅读依据与回答内容保持一致 |
| 编辑后离开 | 保存并继续 / 放弃修改 / 继续编辑 | 阻止静默丢失内容 |
| 刷新与重新打开 | 草稿留在本机，重新打开时提供恢复入口；已保存示例记录也保留 | 让体验可以跨一次浏览器会话继续 |
| 编辑格式 | 加粗、斜体、标题、列表、引用、代码；Markdown 编辑与阅读预览 | 提供适度的结构表达，保留可移植文本 |
| 拟标题 | 仅点击“拟个标题”后生成示例建议，可继续修改；替换已有标题会确认 | 保持标题可选与用户主动控制 |
| 保存 AI 回答 | 将完整回复保存为标题留空的新笔记 | 让对话结果回到记录中 |
| 删除笔记 | 确认后删除，并提供短时间撤销 | 允许恢复误操作 |
| 设置 | 原任务上方的模态设置，关闭后保留编辑/对话草稿；支持嵌套说明弹窗 | 避免设置重建正在进行的任务 |
| 桌面相关笔记 | 窗口宽度 ≥1200px 时与正文并排，较窄窗口使用抽屉 | 查看线索时保留原内容 |
| 个人画像 | 具体关注观察 + 原笔记入口，去除能力分数和装饰性氛围色 | 给理解提供依据，不将记录频次当作能力评级 |

## 收紧的重复入口

笔记保留侧栏全局“新建笔记”和主内容快速记录；移除最近区加号、页首新建、顶部新建。阅读页编辑与更多保留在正文旁。灵感只保留页首生成按钮。对话模式只在顶栏选择。设置统一从账户菜单进入。

## 功能边界

- 所有 AI 回答、开场提问、拟标题、灵感和画像都是本地模拟。演示内容、参考资料与结论不代表真实检索或真实模型能力。
- 格式编辑当前采用轻量 Markdown。正式产品如采用现有富文本编辑器，应复用视觉与操作层级，并设计好文本格式互通，而不是直接替换现有存储格式。
- 本地保存用于原型体验，不等同于云同步、账号服务、跨标签页实时协作或数据备份。更换浏览器/来源地址后不会共享记录；清理浏览器数据会移除记录。
- 设置里的定期发现只演示授权和开关状态，不会启动后台调度。账号、密码、订阅等沿用基底的界面模拟，不连接真实服务。
- 可以通过“数据与隐私 → 导出”导出已保存记录；“恢复初始示例”重置演示内容。预览全部依赖内置，无字体/CDN/脚本请求。
