# 发现阅读 · 独立原型

验证「空白对话短卡 → 独立阅读 → 继续探索」能否兼顾直接提问与充分阅读。使用固定的合成笔记和内存草稿，刷新后恢复样例。关闭阅读页或退回新对话时，当前对话和成果草稿仍留在原型中。无真实 API、模型、账号或保存。

在仓库根目录运行 `python3 -m http.server 8769 --bind 127.0.0.1 --directory design-preview/note-discovery-reader`，然后打开 http://127.0.0.1:8769/ 。也可以直接打开 index.html。

待确认：短卡能否让用户判断值得打开，全文阅读是否够宽松，证据与继续探索的顺序是否自然。
