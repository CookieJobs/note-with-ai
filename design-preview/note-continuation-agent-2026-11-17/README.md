# 从你的笔记继续：交互原型

独立 HTML 演示，不依赖外部资源或后端。可直接打开 `index.html`；也可在项目根目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/design-preview/note-continuation-agent-2026-11-17/`。

页面顶部“原型控制 · 模拟数据”可切换三类发现和运行状态；该区域是演示工具，不属于产品界面。侧栏仅展示静态工作区标签。

交互包括：展开原文证据、来源原文对话框、继续探索与带来源模拟会话、输入问题与模拟答复、编辑并幂等模拟保存草稿、三种反馈及撤销、自动发现开关、浏览其他发现、空结果/分析中/额度耗尽/失败状态、深浅主题切换和可见键盘焦点。聊天、反馈和草稿仅驻留页面内存，刷新即清除；保存前可编辑，模拟保存后不重复创建。普通对话不隐式绑定某条发现。
